# NovaCart — responsive shopping storefront

A self-contained front-end assignment inspired by common ecommerce layout patterns. It uses original branding, custom layout and JavaScript interactions; it does not use Amazon's logo or source code.

## Run locally
1. Extract `novacart-storefront.zip`.
2. Open `index.html` in a browser. No build step or package install is required.
3. An internet connection is needed for Google Fonts and the Unsplash product/hero images.

## Included interactions
- Search products by name, category, and tag
- Category filtering from navigation and category tiles
- Sort by featured, price, rating, or discount
- Add/remove products, quantity controls, subtotal, and cart count
- Wishlist toggles
- Auto-advancing hero slider with next/previous and dots
- Mobile navigation menu
- Delivery location prompt, account/order info modals, newsletter form feedback
- Responsive desktop, tablet, and mobile layouts

## Notes
- This is a front-end demo. Sign-in, payment, order placement, and newsletter subscription are intentionally simulated; there is no backend or real checkout.
- Product images are remotely hosted on Unsplash. If an image URL changes or is unavailable, replace it in `script.js`.
