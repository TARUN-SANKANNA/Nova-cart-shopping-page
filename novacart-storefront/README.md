NovaCart – Responsive Shopping Website
Project Description
NovaCart is a responsive front-end shopping website inspired by common e-commerce design patterns. It provides a promotional home page, product categories, product cards, search and sorting controls, and a shopping cart. The project uses original branding and demo product content; it is not affiliated with Amazon.
Technologies Used
- HTML5 – page structure and content
- CSS3 – styling, Flexbox, CSS Grid, hover effects and responsive media queries
- JavaScript – product rendering, search, category filtering, sorting, banner slider, wishlist and cart interactions
- Unsplash image URLs – demo product and banner imagery
Features Implemented
- Header with brand, delivery location, search, language, account, orders and cart
- Category navigation and category tiles
- Three-slide promotional banner with previous/next controls and automatic rotation
- Product catalogue with 16 demo products
- Search by product name, category or tag
- Filter products by category
- Sort by featured, price, rating or discount
- Add products to cart, update quantities, remove items and view subtotal
- Cart item count
- Wishlist toggle
- Responsive desktop, tablet and mobile layout
- Mobile navigation menu
- Demo account, orders, language and checkout dialogs
- Newsletter form feedback
- Footer with informational links
Instructions to Run the Project
1. Download or clone this repository.
2. Keep index.html, styles.css and script.js in the same folder.
3. Open index.html in a modern web browser.
4. Alternatively, open the folder in Visual Studio Code and run it with the Live Server extension.
5. An internet connection is required for the remote Unsplash images. The website does not require a package installation or build step.
Challenges Faced During Development
- Organizing the header, navigation, banner, category sections, product grid and footer into a clear page structure.
- Making product cards and category layouts adapt to desktop, tablet and mobile screen widths.
- Connecting search, category filters and sorting so they update the displayed products together.
- Keeping the cart count, quantities and subtotal synchronized when products are added, removed or updated.
- Building a banner slider with working navigation controls and automatic rotation.
- Keeping the CSS understandable and avoiding the need for a CSS framework
